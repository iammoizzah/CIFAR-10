# Section B — CIFAR-10 Robustness (Inception-style CNN, trained from scratch)

Train a small Inception-style CNN on 500 CIFAR-10 images (400 train / 100 validation) so that it stays
accurate on a corrupted test set (`shifted_test`) as well as on the original test set (`clean_test`).

## Rules and where they are enforced

| Rule                                | Where                                                                                                    |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------- |
| No pretrained weights               | Model is built from scratch in `SmallInceptionCNN`                                                       |
| <= 1,000,000 trainable parameters   | `assert n_params <= 1_000_000` (about 112,714 params)                                                    |
| Inception-style module              | `InceptionBlock`: parallel 1x1, 3x3, 5x5 branches with 1x1 reductions + pool branch                      |
| Never tune on test data             | Test loaders are created only in the final cell (12b); the final config is chosen by validation accuracy |
| Augmentation on the fly, train only | `make_train_transform` is used in `CIFARIndexDataset.__getitem__`; nothing is saved to disk              |
| Max 60 epochs, fixed seeds, 3 runs  | `FINAL_EPOCHS = 60`, `RUN_SEEDS = [42, 123, 2026]`, results reported as mean ± std                       |

## shifted_test

Generated by the code (fixed seed 9000, cached to `section_b_outputs/shifted_test_seed9000.npz`) from the 10,000
CIFAR-10 test images: rotation up to ±25°, brightness and contrast changes, random rectangular occlusion
(~25% area), and one hidden corruption (random grayscale or channel swap). The training pipeline does not copy it.

## How to reproduce

```bash
git clone https://github.com/iammoizzah>/<CIFAR-10>.git
cd <your-repo>
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# optional 2-epoch smoke test (1 seed)
QUICK_TEST=1 python section_b_cifar10_robustness.py

# full run: 8 configurations x 3 seeds x up to 60 epochs
python section_b_cifar10_robustness.py
# or open section_b_cifar10_robustness.ipynb and Run All (Colab with a GPU is fine)
```

CIFAR-10 downloads automatically into `./data`. Edit `GITHUB_URL` near the top of the script before the final run.

## Outputs (`section_b_outputs/`)

- `ablation_val_summary.csv` – validation-only summary used for model selection
- `ablation_summary.csv`, `ablation_raw_results.csv` – validation + test results (mean ± std over seeds)
- `single_change_gains.csv` – shifted-test gain of each single change
- `shifted_test_ablation.png`, `clean_vs_shifted_accuracy.png`, `baseline_learning_curves.png`
- `reproducibility_manifest.json` – seeds, indices, versions, hyperparameters
- `Section_B_Summary.docx` – one-page summary generated from the real results

## Protocol notes

- Hyperparameters (AdamW lr 1e-3, wd 1e-4, batch 32, cosine schedule, patience 10, Mixup alpha 0.2) are fixed
  in advance; configurations are compared on validation accuracy only.
- Test data is evaluated once, after all choices are made. The "single change that helped most" analysis is
  post-hoc reporting and does not influence model selection.
- Results are deterministic for a given hardware and software stack; small differences can occur across GPUs.
